# 0012 文档版标注清单的三种布局与页边状态条

日期：2026-10-27｜状态：已采纳｜范围：圈批·文档（diple-docs）、desktop-kit

## 背景

V2 的审阅页把标注清单写死在右侧（`grid-template-columns: minmax(0,1fr) minmax(280px,380px)`），窄于 720px 时固定占下方 45%，不能收起。用户读长文时想拿回这块宽度，但收起后仍要看得见每条标注的状态（内部调研笔记，没有公开）。

## 决定

1. **一个状态机，三种布局**（`review/list-panel.js` 的 `listMode`）：
   - `open`：清单在右侧，宽度由 CSS 变量 `--er-list-w` 决定（默认 340，范围 260–560）；页面缩窄时先压窄清单，给文档保留 300px，清单不低于 260px；实际可拖最大值同样受此限制；压窄不改写记住的宽度；
   - `rail`：清单收成 28px 的页边状态条；
   - `sheet`：页面宽度低于 560px 时自动进入（V3-D2-I 下调，原为不超过 720px），底部 36px 折叠栏，点开后占下方 45%。
   - 窄不窄由 `ResizeObserver` 量 `.er-page` 决定，不再用 CSS 容器查询，因为三种布局渲染的元素不同。
2. **全局记住**：`ctx.storage['listPanel'] = { collapsed, width, sheetOpen }`，不按文件记。收起是阅读习惯，用户不想每个文件再收一次。宽屏的 `collapsed` 和窄屏的 `sheetOpen` 分开记。
3. **临时展开不写进存储**：清单收起时新建标注，卡片里要写意见，清单在编辑期间临时展开（`peek = editing != null`），写完回到收起。V3-D 第 5 项（在原文下方直接输入）落地后，这条分支可以删掉。
4. **拖拽手柄放进 desktop-kit**（`ResizeHandle`、`resizeWidth`、`RESIZE_HANDLE_CSS`）：拖动时每帧最多回调一次 `onLive`，由调用方直接写 CSS 变量，不触发 React 渲染；松手时 `onCommit` 一次。移动不超过 4px 算单击，单击收起；双击恢复默认宽度；拖到 156px（0.6 × 最小宽度）以下松手就收起。键盘：←/→ 每次 16px，Home/End，Enter 收起；RTL 下方向取反。
5. **状态条的刻度用百分比定位**：`top = (标记顶部 − 滚动框顶部 + scrollTop) / scrollHeight`。滚动时刻度不动，也不读布局；只在重新绘制标记、布局切到 `rail`、或滚动框和文档尺寸变化时重新测量（沿用 V2.1 图钉的性能规则，`data-er-measures` 计数供测试使用）。暂时不画视口框，因为画它就要在滚动时读 `scrollTop`。
6. **刻度颜色和文档标记用同一套 token**（`MarkLook.ACCENT / ANSWER / WARN`）：待发是主题色，已发是淡主题色，已回应是 ANSWER，原文已变是 WARN，已解决是 `--ui-text-quaternary`。已解决也画刻度，这是任务单的要求，和调研里「不画」的建议不同。
7. **悬停预览用插件自己的浮层**，不用 SDK 的 Popover：Popover 由点击触发，悬停预览要受控开合，并且要能把指针移进浮层。浮层用 `translateY(-p%)` 跟着刻度位置偏移，所以总在状态条的高度范围内，不需要测量。
8. **「未处理」的定义**：待发、原文已变、已回应，而且状态不是已解决（`model.isUnhandled`）。「上一条 / 下一条」按文档顺序走，到头后循环（`model.stepUnhandled`）。焦点留在按钮上，卡片滚进视野但不抢焦点。
9. **快捷键**：「切换标注清单」默认 ⌘⌥B。宿主默认键位（`lib/keybinds/actions.ts`、`contrib/controller.tsx`）和聊天版（⌘⇧E、⌘⇧↩）都没有占用这个键。调研里的另一个候选 ⌘⇧\ 已被宿主的「布局编辑模式」占用。「上一条 / 下一条未处理」不设默认键，用户可以在 设置 › 快捷键 里自己绑定。快捷键只在设置页显示（V2.1 #3）。

## 后果

- desktop-kit 的 `index.js` 多了一行导出（ResizeHandle），聊天版以后的面板也能用这个手柄。
- 原文已变（lost）的条目导出时不带行号（B7）：`model.exportLine` 对这类条目返回 null。交接 payload 的 `origin` 省略 `line`，「复制给 AI」的标签只写文件名。envelope 遇到没有行号的情况本来就只写路径。
- 新增测试 `tests/desktop/v3d-panel.test.mjs`。
