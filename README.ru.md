# Diple Docs — выделяйте и комментируйте документы Markdown для ИИ (плагин Hermes Desktop)

Откройте файл `.md` в Hermes Desktop, выделяйте фрагменты, пишите к ним комментарии и передавайте их ИИ в чате; каждая пометка помнит своё место в файле и показывает, отправлена ли она, получен ли ответ или она решена.

> **Название.** Диплé (›) — знак, которым древнегреческие писцы отмечали на полях строку, к которой есть комментарий. Diple Docs (圈批·文档) — участник семейства для документов; [Diple](https://github.com/waiclay-349687/hermes-diple) (圈批) — участник для чата.

> **Неофициальный.** Это плагин сообщества. Его не создавали, не проверяли и не поддерживают Nous Research и проект Hermes Agent.

## Возможности

- **Страница документа только для чтения** — открывает файл `.md` / `.markdown` в отдельной вкладке, там же, где открывается предпросмотр Hermes: справа от чата. Виды **Оформленный** и **Исходный**, **Обновить** и **Показать в Finder**. Плагин никогда не изменяет документ.
- **Пометить выделенное** — выделите текст и нажмите **Пометить**. Редактор открывается прямо под фрагментом, а выделение получает лёгкую временную подсветку, чтобы было видно, что вы помечаете. Пока ничего не добавлено.
- **В список — только после сохранения** — **Сохранить** с комментарием создаёт *комментарий* (ИИ обязан на него ответить); **Сохранить** с пустым полем создаёт *выделение* (только фон). Лишь тогда пометка попадает в список и становится текущей. Пустой черновик исчезает при щелчке снаружи или по <kbd>Esc</kbd>. Черновик с текстом не теряется при щелчке снаружи, переходе к другой пометке, закрытии или перезагрузке страницы; удаляется он только по <kbd>Esc</kbd> или **×**. Когда файл обновляется, черновик следует за своим фрагментом; если фрагмент не найден, вас попросят выбрать его заново. Если другое окно тем временем сохранило тот же фрагмент, вы выбираете: **Оставить существующий**, **Заменить моим** или **Объединить**.
- **Список пометок** — все пометки файла в порядке документа, с фильтрами (Все, К отправке, Отправлено, Есть ответ, Оригинал изменён, Решено). На карточке: перейти к фрагменту, изменить комментарий, отметить решённым или открыть снова, удалить (с отменой), отправить эту.
- **Предыдущая / следующая необработанная** — две стрелки в заголовке списка (и в полосе состояния на полях) переходят по ещё не решённым пометкам.
- **Массовая очистка с отменой** — меню **⋯** списка очищает все, решённые, отправленные или с ответом, с изменённым оригиналом или отфильтрованные, отмечает все решёнными или копирует все как Markdown. Любую очистку можно отменить.
- **Показать или скрыть список с панели инструментов** — переключатель в правом конце панели документа (на нём видно, сколько пометок ещё открыто). Скрытый список оставляет **полосу состояния на полях**: по одной отметке на пометку в её месте документа, цвет показывает состояние; наведите на отметку для предпросмотра, щёлкните, чтобы перейти.
- **Узкие окна** — если страница слишком узка, чтобы список поместился рядом с документом, он становится нижней панелью, которая раскрывается и сворачивается.
- **Следит за изменениями файла** — когда файл на диске меняется, страница перезагружается (пока вы пишете комментарий, она ждёт) и снова находит каждый фрагмент. Не найденный фрагмент помечается **Оригинал изменён** и сохраняет прежний текст, а на карточке есть **Выбрать новый оригинал**.
- **Передать в чат** — **Отправить N ▾** передаёт пометки в [Diple](https://github.com/waiclay-349687/hermes-diple): в список к отправке беседы, чтобы они ушли с вашим следующим сообщением, или сразу. Затем карточка показывает **Отправлено**, а после ответа ИИ — **Есть ответ**, со ссылкой на беседу. **Копировать для ИИ** в том же меню вместо этого копирует их как Markdown.
- **Карточка «Открыть в Diple Docs» в чате** — когда ИИ пишет файл `.md`, в конце его ответа появляется карточка, открывающая файл для пометок (можно отключить). Недавние документы есть и в палитре команд.

Интерфейс плагина доступен на всех языках Hermes Desktop: **English, 简体中文, 繁體中文, 日本語, العربية, Русский, Français, Deutsch и Español** (арабский справа налево). По умолчанию он следует языку приложения; язык можно выбрать и в настройках плагина.

## Установка

У плагина две половины: десктопный плагин (`plugin.js`) и небольшой бэкенд на Python (`plugins/diple-docs/`). Нужны обе. Чтобы отправлять пометки в чат, установите также [Diple](https://github.com/waiclay-349687/hermes-diple) (см. «Плагин-компаньон» ниже). В командах ниже `~/.hermes` — ваш домашний каталог Hermes; для именованного профиля используйте `~/.hermes/profiles/<name>`.

### Вариант A: скачать релиз

1. Скачайте `plugin.js`, `plugin.js.sha256`, `diple-docs-python-0.1.0.zip` и `diple-docs-python-0.1.0.zip.sha256` из [последнего релиза](https://github.com/waiclay-349687/hermes-diple-docs/releases) и проверьте их:

   ```bash
   shasum -a 256 -c plugin.js.sha256
   shasum -a 256 -c diple-docs-python-0.1.0.zip.sha256
   ```

2. Разложите их по местам:

   ```bash
   mkdir -p ~/.hermes/desktop-plugins/diple-docs ~/.hermes/plugins
   cp plugin.js ~/.hermes/desktop-plugins/diple-docs/plugin.js
   unzip -o diple-docs-python-0.1.0.zip -d ~/.hermes/plugins/
   ```

3. Включите бэкенд и перезапустите Hermes Desktop:

   ```bash
   hermes plugins enable diple-docs
   ```

### Вариант B: из исходников

Нужен Node.js 22 или новее.

```bash
git clone https://github.com/waiclay-349687/hermes-diple-docs.git
cd hermes-diple-docs
npm install
node scripts/install.mjs --home ~/.hermes --no-enable
hermes plugins enable diple-docs
```

`scripts/install.mjs` собирает `plugin.js` и копирует обе половины в домашний каталог Hermes, заданный `--home` (сам он его не угадывает). После этого перезапустите Hermes Desktop: половина на Python загружается только при запуске приложения.

## Использование

1. Откройте документ: в палитре команд (<kbd>⌘K</kbd>) выберите «Diple Docs: Открыть документ…» или «Diple Docs: Недавние документы…» либо нажмите **Открыть** на карточке «Открыть в Diple Docs» в чате.
2. Выделите фрагмент и нажмите **Пометить**. Напишите комментарий или оставьте поле пустым для выделения и нажмите **Сохранить** (или <kbd>Enter</kbd>; <kbd>Shift</kbd>+<kbd>Enter</kbd> добавляет строку). Пометка появится в списке и подсветкой на фрагменте.
3. Продолжайте. Стрелками в заголовке списка переходите по открытым пометкам, а переключателем на панели инструментов скрывайте список, когда нужна ширина.
4. Откройте **Отправить N ▾**: выберите эту пометку или все неотправленные в файле, затем текущую беседу — чтобы добавить их в её список к отправке или отправить сразу. Или выберите **Копировать для ИИ**.
5. Когда ИИ ответит, карточки покажут **Есть ответ**. Отметьте решённое и в конце очистите его через меню **⋯**.

**Сохранить и отправить** в редакторе сначала сохраняет, затем отправляет эту пометку в текущую беседу.

### Сочетания клавиш

| Действие | По умолчанию | Примечание |
| --- | --- | --- |
| Пометить выделенное на странице документа | <kbd>⌘⇧E</kbd> | То же сочетание, что у Diple; его обрабатывает сама страница. Можно также назначить «Пометить выделенное (страница документа)» в настройках клавиатуры приложения |
| Показать или скрыть список пометок | <kbd>⌘⌥B</kbd> | Переназначается |
| Предыдущая / следующая необработанная | нет | Назначьте в настройках клавиатуры приложения |

На рабочих элементах (кнопка, редактор, список, полоса состояния) эти клавиши не показываются; их перечисляет страница настроек плагина.

В Windows и Linux <kbd>⌘</kbd> — это <kbd>Ctrl</kbd>. В палитре команд (<kbd>⌘K</kbd>) есть также «Пометить выделенное (страница документа)» и «Diple Docs: Настройки» (на языке интерфейса).

## Как это работает

### Что получает ИИ

Diple Docs сам не общается с ИИ. **Отправить** передаёт пометки в Diple через события плагинов (протокол передачи, [ADR 0007](docs/adr/README.md)); Diple кладёт их в список к отправке беседы рядом с пометками из чата и отправляет так же, как свои: пузырь в чате остаётся коротким, а ИИ получает каждый фрагмент целиком с файлом и строкой, ваш комментарий и правило отвечать на каждый комментарий. Diple сообщает, что отправлено и на что получен ответ, и карточки обновляются.

**Копировать для ИИ** кладёт те же пометки в буфер обмена как Markdown (фрагмент цитатой, затем ваш комментарий) — для любого чата или инструмента.

### Место каждой пометки

Пометка хранит фрагмент, строку и достаточно окружающего текста, чтобы найти его снова. После изменения файла плагин ищет фрагмент в новом тексте; если контекст недостаточно уникален, он не гадает: пометка получает статус **Оригинал изменён** и сохраняет прежний текст.

### Где хранятся данные

- Пометки, их состояние и список недавних документов: SQLite в `~/.hermes/plugin-data/diple-docs/data.db`, по пути файла. Рядом с вашими документами ничего не записывается.
- Выбор раскладки (ширина списка, показан или скрыт, вид): хранилище десктопных плагинов Hermes Desktop (ключи с префиксом `hermes.plugin.diple-docs.`).

Проектные решения описаны в [docs/adr](docs/adr/README.md), общая структура — в [docs/architecture.md](docs/architecture.md).

## Конфиденциальность

Всё остаётся на вашем компьютере. Плагин сам не делает сетевых запросов и не собирает телеметрию. Он читает только документы, которые вы открываете, и отказывается читать места с учётными данными или внутренними данными Hermes (например, `~/.ssh` или `.env` Hermes). Пометки попадают к поставщику модели только когда вы отправляете их в беседу — так же, как набранный вами текст.

## Известные ограничения

Основные (полный список с причинами — в [docs/known-limitations.md](docs/known-limitations.md)):

- Для отправки нужен Diple. Без него первая отправка 3 секунды ждёт ответа (10 секунд, если это другая беседа: Diple сначала открывает её), затем страница сообщает, что Diple не отвечает, и отключает отправку; список, комментарии, **Копировать для ИИ** и **Копировать все как Markdown** продолжают работать.
- Получатель — всегда существующая беседа: создать новую отсюда нельзя, потому что `newChat()` из SDK не возвращает id сессии. [#6](https://github.com/waiclay-349687/hermes-diple-docs/issues/6)
- В оформленном виде выделение внутри таблицы, сырого HTML или сноски может не совпасть с исходником; тогда страница просит выделить его снова в исходном виде.
- Переименованный или перемещённый файл начинается с пустого списка.
- Если другой плагин тоже переписывает ответы ИИ, карточка «Открыть в Diple Docs» может пропасть (хост оставляет только первое переписывание); файл всё равно есть в недавних документах.

## Совместимость

Проверено с Hermes Agent **v0.22.5 (2026.9.24)**, коммит `bf0203a` (2026-10-22), на macOS, вместе с Diple 0.2.2. Нужен Hermes Desktop (один CLI десктопные плагины не загружает). Другие версии могут работать, но не проверялись; пожалуйста, сообщайте о результатах.

## Плагин-компаньон: Diple

[Diple](https://github.com/waiclay-349687/hermes-diple) (圈批) — участник семейства для чата: выделяйте и комментируйте фрагменты беседы, держите их в списке к отправке над полем ввода и отправляйте с вашим следующим сообщением; ИИ отвечает на каждый комментарий, а между ответом и фрагментом можно переходить в обе стороны.

- **Без Diple**: открытие документов, пометки, список, фильтры, решение, полоса состояния на полях, **Копировать для ИИ** в меню отправки и **Копировать все как Markdown** работают. Diple нужен только для отправки в беседу.
- **С Diple**: **Отправить N ▾** кладёт пометки документа в список к отправке беседы, рядом с пометками из чата, в виде чипов над полем ввода; они уходят с вашим следующим сообщением, а если выбрать в меню саму беседу — сразу. Ответы ИИ помечают, на какой комментарий они отвечают, и карточки здесь становятся **Отправлено**, затем **Есть ответ**.

Это два отдельных плагина с отдельными репозиториями и релизами; ставьте любой или оба. Во время работы они не делят код: каждый включает собственную копию общего ядра.

## Чем отличается

Встроенный предпросмотр Hermes Desktop показывает файл Markdown и умеет его редактировать. Diple Docs никогда не редактирует: он для рецензирования. Он хранит список пометок для каждого файла между сессиями, находит их снова после изменений, отслеживает каждую от «к отправке» до «есть ответ» и «решено» и передаёт их в чат через Diple.
