# Diple Docs（圈批·文档）— Markdown 文書にハイライトとコメントを付けて AI に渡す（Hermes Desktop プラグイン）

Hermes Desktop で `.md` ファイルを開き、文章にハイライトやコメントを付けて、チャットの AI に渡します。各注釈はファイル内の位置を覚えていて、送信待ち・送信済み・回答済み・解決済みのどれかを表示します。

> **名前の由来。** diple（›）は古代ギリシャの写字生が欄外に付けた記号で、その行に注釈があることを示しました。Diple Docs（圈批·文档）はこのファミリーの文書担当で、[Diple](https://github.com/waiclay-349687/hermes-diple)（圈批）がチャット担当です。

> **非公式。** これはコミュニティ製のプラグインです。Nous Research や Hermes Agent プロジェクトが作成・審査・サポートしているものではありません。

## 機能

- **読み取り専用の文書ページ** — `.md` / `.markdown` ファイルを専用のタブで開きます。開く位置は Hermes のプレビューと同じで、チャットの右側です。**表示** と **ソース** の 2 つの表示形式、**再読み込み**、**Finder で表示** があります。プラグインが文書を書き換えることはありません。
- **選択範囲に注釈** — テキストを選択して **注釈** をクリックします。編集パネルがその文章のすぐ下に開き、選択範囲には一時的な薄い色が付くので、どこに注釈しているかがわかります。この時点ではまだ何も追加されません。
- **保存して初めてリストに入る** — コメントを書いて **保存** するとコメントに（AI は必ず答えます）、空のまま **保存** するとハイライトになります（背景色だけ）。そこで初めてリストに入り、現在の注釈になります。空の下書きは外側をクリックするか <kbd>Esc</kbd> で破棄されます。文字を書いた下書きは、外側のクリック、別の注釈への切り替え、ページを閉じる・再読み込みでは失われません。破棄されるのは <kbd>Esc</kbd> か **×** のときだけです。ファイルが更新されると下書きは原文を追いかけ、原文が見つからないときは選び直すよう案内します。別のウィンドウが同じ箇所を先に保存していたら、**既存を残す**・**自分ので置き換え**・**結合** から選べます。
- **注釈リスト** — ファイルのすべての注釈を文書の順に並べ、「すべて・送信待ち・送信済み・回答済み・原文が変更・解決済み」で絞り込めます。カードでは、原文へ移動、コメントを編集、解決済みにする／再び開く、削除（元に戻せます）、この 1 件を送信ができます。
- **前 / 次の未処理の注釈** — リストの見出し（とページ端のステータスバー）にある 2 つの矢印で、まだ解決していない注釈を順にたどれます。
- **一括クリア（元に戻せます）** — リストの **⋯** メニューで、すべて・解決済み・送信済みまたは回答済み・原文が変更・絞り込み中のものをクリアしたり、すべて解決済みにしたり、すべて Markdown でコピーしたりできます。どのクリアも元に戻せます。
- **ツールバーでリストを表示 / 非表示** — 文書ツールバーの右端のスイッチです（未処理の件数も表示します）。非表示にすると、リストは **ページ端のステータスバー** になります。注釈ごとに文書内の位置に目盛りがあり、色が状態を表します。目盛りにポインタを乗せるとプレビュー、クリックするとその場所へ移動します。
- **狭いウィンドウ** — ページが狭くて文書の横にリストを置けないときは、リストが開閉できる下部バーになります。
- **ファイルの変更に追従** — ディスク上のファイルが変わるとページを読み込み直し（コメントを書いている間は待ちます）、各注釈の原文を見つけ直します。見つからないものは **原文が変更** と表示され、元の文章を残したまま、カードに **原文を選び直す** が出ます。
- **チャットに渡す** — **N 件を送信 ▾** で注釈を [Diple](https://github.com/waiclay-349687/hermes-diple) に渡します。会話の送信待ちリストに入れて次のメッセージと一緒に送るか、すぐに送信します。その後カードは **送信済み**、AI が答えると **回答済み** になり、会話へのリンクが付きます。同じメニューの **AI 用にコピー** なら Markdown としてコピーします。
- **チャットの「Diple Docs で開く」カード** — AI が `.md` ファイルを書くと、回答の末尾にそのファイルを開くカードが付きます（オフにできます）。最近の文書はコマンドパレットにもあります。

プラグインの UI は Hermes Desktop のすべての言語に対応しています：**English、简体中文、繁體中文、日本語、العربية、Русский、Français、Deutsch、Español**（アラビア語は右から左）。既定ではアプリの言語に合わせ、プラグインの設定で個別に選ぶこともできます。

## インストール

プラグインは 2 つの部分からなります：デスクトッププラグイン（`plugin.js`）と小さな Python バックエンド（`plugins/diple-docs/`）。両方が必要です。注釈をチャットに送るには [Diple](https://github.com/waiclay-349687/hermes-diple) も入れてください（下の「姉妹プラグイン」を参照）。以下のコマンドの `~/.hermes` は Hermes ホームです。名前付きプロファイルなら `~/.hermes/profiles/<name>` に置き換えてください。

### 方法 A：リリースをダウンロード

1. [最新リリース](https://github.com/waiclay-349687/hermes-diple-docs/releases)から `plugin.js`、`plugin.js.sha256`、`diple-docs-python-0.1.0.zip`、`diple-docs-python-0.1.0.zip.sha256` をダウンロードし、検証します：

   ```bash
   shasum -a 256 -c plugin.js.sha256
   shasum -a 256 -c diple-docs-python-0.1.0.zip.sha256
   ```

2. 所定の場所に置きます：

   ```bash
   mkdir -p ~/.hermes/desktop-plugins/diple-docs ~/.hermes/plugins
   cp plugin.js ~/.hermes/desktop-plugins/diple-docs/plugin.js
   unzip -o diple-docs-python-0.1.0.zip -d ~/.hermes/plugins/
   ```

3. バックエンドを有効にして Hermes Desktop を再起動します：

   ```bash
   hermes plugins enable diple-docs
   ```

### 方法 B：ソースから

Node.js 22 以降が必要です。

```bash
git clone https://github.com/waiclay-349687/hermes-diple-docs.git
cd hermes-diple-docs
npm install
node scripts/install.mjs --home ~/.hermes --no-enable
hermes plugins enable diple-docs
```

`scripts/install.mjs` は `plugin.js` をビルドし、両方の部分を `--home` で指定した Hermes ホームにコピーします（推測はしません）。そのあと Hermes Desktop を再起動してください。Python 側はアプリの起動時にしか読み込まれません。

## 使い方

1. 文書を開きます：コマンドパレット（<kbd>⌘K</kbd>）で「Diple Docs: 文書を開く…」か「Diple Docs: 最近の文書…」を選ぶか、チャットの「Diple Docs で開く」カードで **開く** をクリックします。
2. 文章を選択して **注釈** をクリックします。コメントを書くか、ハイライトなら空のままにして **保存** をクリックします（または <kbd>Enter</kbd>。<kbd>Shift</kbd>+<kbd>Enter</kbd> で改行）。注釈がリストに現れ、原文に色が付きます。
3. 読み進めます。リストの見出しの矢印で未処理の注釈をたどり、幅が欲しいときはツールバーのスイッチでリストを隠します。
4. **N 件を送信 ▾** を開きます：「この 1 件」か「このファイルの未送信すべて」を選び、次に現在の会話を選んで送信待ちリストに追加するか、すぐに送信します。**AI 用にコピー** を選ぶこともできます。
5. AI が答えると、カードは **回答済み** になります。片付いたものを解決済みにし、最後に **⋯** メニューでクリアします。

編集パネルの **保存して送信** は、まず保存し、その 1 件を現在の会話に送ります。

### ショートカット

| 操作 | 既定 | 備考 |
| --- | --- | --- |
| 文書ページで選択範囲に注釈 | <kbd>⌘⇧E</kbd> | Diple と同じキーで、文書ページ自身が処理します。アプリのキーボード設定で「選択範囲に注釈（文書ページ）」に別のキーを割り当てることもできます |
| 注釈リストを表示 / 非表示 | <kbd>⌘⌥B</kbd> | 変更可能 |
| 前 / 次の未処理の注釈 | なし | アプリのキーボード設定で割り当てます |

作業中の画面（ボタン、パネル、リスト、ステータスバー）にはキーキャップを表示しません。プラグインの設定ページに一覧があります。

Windows と Linux では <kbd>⌘</kbd> は <kbd>Ctrl</kbd> です。コマンドパレット（<kbd>⌘K</kbd>）には「選択範囲に注釈（文書ページ）」と「Diple Docs: 設定」もあります（UI の言語で表示）。

コマンドパレット（「Diple Docs: 設定」）かアプリの設定から開きます。

| 設定 | 既定 | 内容 |

| 言語 | アプリに合わせる | アプリに合わせるか、9 言語のどれか（各言語は自身の名前で表示）。 |
| AI が `.md` ファイルを書いたら「Diple Docs で開く」カードを付ける | オン | 回答の末尾に、書いたファイルを開くカードが付きます。オフならコマンドパレットから開きます。 |

## 仕組み

### AI が受け取るもの

Diple Docs 自身は AI とやり取りしません。**送信** はプラグインイベントで注釈を Diple に渡し（引き渡しプロトコル、[ADR 0007](docs/adr/README.md)）、Diple はそれを会話の送信待ちリストに、チャットで付けた注釈と並べて入れ、自分の注釈と同じ方法で送ります。チャットの吹き出しは短いままで、AI は各文章の全文とファイル名・行、あなたのコメント、そして「すべてのコメントに答える」というルールを受け取ります。Diple は何が送られ、何に回答があったかを知らせ、カードがそれに合わせて更新されます。

**AI 用にコピー** は同じ注釈を Markdown（原文を引用、その後にコメント）でクリップボードに入れます。どのチャットやツールでも使えます。

### 各注釈の位置

注釈は原文、行、そして見つけ直すのに十分な前後の文脈を保存します。ファイルが変わると新しい本文の中から原文を探し、文脈が十分に一意でなく確信が持てないときは推測しません。その注釈は **原文が変更** となり、元の文章を残します。

### データの保存場所

- 注釈とその状態、最近の文書の一覧：SQLite（`~/.hermes/plugin-data/diple-docs/data.db`）に、ファイルのパスごとに保存します。文書の隣にファイルを書くことはありません。
- レイアウトの選択（リストの幅、表示 / 非表示、表示形式）：Hermes Desktop のデスクトッププラグインストレージ（キーの接頭辞 `hermes.plugin.diple-docs.`）。

設計判断は [docs/adr](docs/adr/README.md) に、全体の構成は [docs/architecture.md](docs/architecture.md) にあります。

## プライバシー

すべてあなたのマシンの中に留まります。プラグイン自身はネットワーク通信をせず、テレメトリもありません。読むのはあなたが開いた文書だけで、認証情報や Hermes の内部データがある場所（たとえば `~/.ssh` や Hermes の `.env`）は拒否します。注釈がモデルのプロバイダに届くのは、あなたが会話に送ったときだけで、自分で入力した文字と同じ扱いです。

## 既知の制限

主なもの（理由を含む全一覧は [docs/known-limitations.md](docs/known-limitations.md)）：

- 送信には Diple が必要です。入っていないと、最初の送信で 3 秒間（別の会話に送るときは、Diple が先にその会話に切り替えるため 10 秒間）応答を待ったあと、Diple が応答しないと表示して送信をオフにします。リスト、コメント、**AI 用にコピー**、**すべて Markdown でコピー** はそのまま使えます。
- 送信先は常に既存の会話です。SDK の `newChat()` がセッション ID を返さないため、ここから新しい会話は作れません。_(issue not filed yet)_
- **表示** 形式では、表・生の HTML・脚注の中の選択がソースと対応しないことがあります。その場合は **ソース** 表示で選び直すよう求められます。
- 名前を変えたり移動したりしたファイルは、空のリストから始まります。
- 別のプラグインも AI の回答を書き換えると、「Diple Docs で開く」カードが消えることがあります（ホストは最初の書き換えしか残しません）。ファイルは最近の文書には残ります。

## 互換性

Hermes Agent **v0.22.5 (2026.9.24)**、コミット `bf0203a`（2026-10-22）、macOS で、Diple 0.2.2 と組み合わせてテストしています。Hermes Desktop が必要です（CLI だけではデスクトッププラグインは読み込まれません）。ほかのバージョンでも動くかもしれませんが未検証です。結果を報告していただけると助かります。

## 姉妹プラグイン：Diple

[Diple](https://github.com/waiclay-349687/hermes-diple)（圈批）はファミリーのチャット担当です。会話の文章にハイライトやコメントを付け、入力欄の上の送信待ちリストにためて、次のメッセージと一緒に送ります。AI はすべてのコメントに答え、回答と原文の間を行き来できます。

- **Diple がない場合**：文書を開く、注釈、リスト、絞り込み、解決済みにする、ページ端のステータスバー、送信メニューの **AI 用にコピー**、**すべて Markdown でコピー** は使えます。Diple が必要なのは会話への送信だけです。
- **Diple がある場合**：**N 件を送信 ▾** で文書の注釈が会話の送信待ちリストに入り、チャットで付けた注釈と一緒に入力欄の上にチップとして並びます。次のメッセージと一緒に送られ、メニューで会話そのものを選べばすぐに送られます。AI の回答はどのコメントへの答えかを示し、ここのカードは **送信済み**、続いて **回答済み** になります。

2 つは別々のプラグインで、リポジトリもリリースも別です。片方だけでも両方でも入れられます。実行時にコードを共有することはなく、それぞれが共有コアの自分用のコピーを同梱しています。

## 類似機能との違い

Hermes Desktop 標準のプレビューは Markdown ファイルを表示し、編集もできます。Diple Docs は編集しません。レビューのためのものです。ファイルごとの注釈リストを会話をまたいで保持し、ファイルが変わっても位置を見つけ直し、各注釈を送信待ちから回答済み、解決済みまで追跡し、Diple を通じてチャットに渡します。
