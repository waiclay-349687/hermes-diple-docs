# 圈批·文檔（Diple Docs）— 在 Markdown 文件上劃線、寫批註，交給 AI（Hermes 桌面版外掛）

在 Hermes 桌面版開啟一份 `.md` 檔案，劃出段落、寫上意見，再交給聊天裡的 AI；每則標註都記住自己在檔案裡的位置，並顯示待發、已發、已回應還是已解決。

> **名字的由來。** Diple（›）是古希臘抄本頁邊的標記，用來把一行文字指向它的註解。圈批·文檔是這個家族裡負責文件的那一個；[圈批（Diple）](https://github.com/waiclay-349687/hermes-diple) 是負責聊天的那一個。

> **非官方外掛。** 這是社群外掛，不是 Nous Research 或 Hermes Agent 專案製作、審核或支援的。

## 功能

- **唯讀的文件頁**——在獨立的分頁裡開啟 `.md` / `.markdown` 檔案，位置和 Hermes 預覽一致：停在聊天右側。有「排版」和「原始碼」兩種檢視，還有「重新整理」和「在 Finder 中顯示」。外掛從不修改文件。
- **標註選取的文字**——選取文字後點「標註」。編輯浮層出現在原文正下方，所選原文帶一層淺淺的暫時底色，看得出正在標哪一段。這時還沒有新增任何條目。
- **儲存後才進清單**——寫了意見再點「儲存」，得到一則*批註*（AI 必須回應）；空著點「儲存」，得到一則*劃線*（只有底色）。儲存之後才進入清單，並成為目前這一則。空草稿點外面或按 <kbd>Esc</kbd> 就被捨棄。寫了字的草稿，點外面、切到別的條目、關閉或重新載入都不會遺失；只有按 <kbd>Esc</kbd> 或點 × 才捨棄。檔案重新整理後，草稿會跟著原文走；找不到原文時，會提示你重新選取。如果另一個視窗已經儲存了同一段，可以選「保留現有」「用我的取代」或「合併」。
- **標註清單**——依文件順序列出這個檔案的全部標註，可以依「全部、待發、已發、已回應、原文已變、已解決」篩選。卡片上可以：跳回原文、編輯意見、標為已解決或重新開啟、刪除（可復原）、單獨傳送這一則。
- **上一則 / 下一則未處理**——清單頂端（以及頁邊狀態列）的兩個箭頭，在還沒解決的標註之間跳轉。
- **批次清除，可復原**——清單的「⋯」選單可以清除全部、已解決、已發或已回應、原文已變或目前篩選出的條目，也可以全部標為已解決，或者全部複製為 Markdown。每一次清除都能復原。
- **在工具列裡顯示或隱藏清單**——開關在文件工具列最右端（上面顯示還有幾則沒處理）。隱藏後清單留下一條**頁邊狀態列**：每則標註在文件中的位置畫一個刻度，顏色表示狀態；滑過刻度可以預覽，點擊就跳過去。
- **窄視窗**——頁面太窄、清單放不下在文件旁邊時，清單改成可以展開、收合的底欄。
- **跟隨檔案變化**——磁碟上的檔案變了，頁面會重新載入（你正在寫意見時會等你寫完），並為每則標註重新找回原文。找不回來的標為「原文已變」，保留原來的文字，卡片上提供「重新選取原文」。
- **交給聊天**——「傳送 N 則 ▾」把標註交給 [圈批](https://github.com/waiclay-349687/hermes-diple)：放進對話的待發列表，隨你的下一則訊息送出，或者立即傳送。之後卡片顯示「已發」，AI 回答後顯示「已回應」，並附對話連結。同一個選單裡的「複製給 AI」則把它們複製成 Markdown。
- **聊天裡的「用圈批·文檔開啟」卡片**——AI 寫了 `.md` 檔案後，回答末尾會出現一張卡片，點開就能標註（可以關掉）。最近的文件也在命令面板裡。

外掛介面支援 Hermes 桌面版的全部語言：**English、简体中文、繁體中文、日本語、العربية、Русский、Français、Deutsch 和 Español**（阿拉伯語從右到左）。預設跟隨 app 的語言，也可以在外掛設定裡單獨指定。

## 安裝

外掛分兩半：桌面外掛（`plugin.js`）和一個小的 Python 後端（`plugins/diple-docs/`），兩個都要裝。要把標註傳到聊天，還要裝 [圈批](https://github.com/waiclay-349687/hermes-diple)（見下面的「姊妹外掛」）。下面指令裡的 `~/.hermes` 是你的 Hermes 主目錄；使用具名 profile 時換成 `~/.hermes/profiles/<name>`。

### 方式 A：下載發佈版

1. 從[最新發佈](https://github.com/waiclay-349687/hermes-diple-docs/releases)下載 `plugin.js`、`plugin.js.sha256`、`diple-docs-python-0.1.0.zip` 和 `diple-docs-python-0.1.0.zip.sha256`，然後校驗：

   ```bash
   shasum -a 256 -c plugin.js.sha256
   shasum -a 256 -c diple-docs-python-0.1.0.zip.sha256
   ```

2. 放到對應位置：

   ```bash
   mkdir -p ~/.hermes/desktop-plugins/diple-docs ~/.hermes/plugins
   cp plugin.js ~/.hermes/desktop-plugins/diple-docs/plugin.js
   unzip -o diple-docs-python-0.1.0.zip -d ~/.hermes/plugins/
   ```

3. 啟用後端，然後重新啟動 Hermes 桌面版：

   ```bash
   hermes plugins enable diple-docs
   ```

### 方式 B：從原始碼安裝

需要 Node.js 22 或更新版本。

```bash
git clone https://github.com/waiclay-349687/hermes-diple-docs.git
cd hermes-diple-docs
npm install
node scripts/install.mjs --home ~/.hermes --no-enable
hermes plugins enable diple-docs
```

`scripts/install.mjs` 會建置 `plugin.js`，並把兩半複製進 `--home` 指定的 Hermes 主目錄（它不會自己猜）。裝完要重新啟動 Hermes 桌面版：Python 那一半只在 app 啟動時載入。

## 使用

1. 開啟文件：在命令面板（<kbd>⌘K</kbd>）裡選「圈批·文檔：開啟文件…」或「圈批·文檔：最近的文件…」，或者在聊天裡的「用圈批·文檔開啟」卡片上點「開啟」。
2. 選取一段文字，點「標註」。寫下意見，或者空著表示劃線，然後點「儲存」（或按 <kbd>Enter</kbd>；<kbd>Shift</kbd>+<kbd>Enter</kbd> 換行）。標註出現在清單裡，原文上也有了底色。
3. 繼續往下看。用清單頂端的箭頭在還沒處理的標註之間跳轉；想要回寬度時，用工具列的開關把清單收起來。
4. 開啟「傳送 N 則 ▾」：先選「這一則」或「本檔案全部未傳送」，再選目前對話，加入它的待發列表或者立即傳送。也可以選「複製給 AI」。
5. AI 回答後，卡片顯示「已回應」。處理完的標為已解決，最後用「⋯」選單清掉。

編輯浮層裡的「儲存並傳送」會先儲存，再把這一則傳到目前對話。

### 快速鍵

| 操作 | 預設 | 說明 |
| --- | --- | --- |
| 在文件頁標註選取的文字 | <kbd>⌘⇧E</kbd> | 和圈批用同一個組合鍵，由文件頁自己處理；也可以在 app 的快速鍵設定裡給「標註選取的文字（文件頁）」另綁一個鍵 |

日常操作的介面（按鈕、浮層、清單、狀態列）上不顯示這些鍵帽，外掛設定頁裡列出了全部快速鍵。

在 Windows 和 Linux 上，<kbd>⌘</kbd> 對應 <kbd>Ctrl</kbd>。命令面板（<kbd>⌘K</kbd>）裡還有「標註選取的文字（文件頁）」和「圈批·文檔：設定」（顯示為你的介面語言）。

## 運作原理

### AI 收到什麼

圈批·文檔自己不和 AI 打交道。「傳送」透過外掛事件把標註交給圈批（交接協定，見 [ADR 0007](docs/adr/README.md)）；圈批把它們放進對話的待發列表，和聊天裡摘的標註排在一起，再依它自己的方式送出：聊天氣泡保持簡短，AI 收到的是每段原文的全文、所在檔案和行號、你的意見，以及「每則意見都要回應」的規則。圈批會回報哪些送出了、哪些得到了回應，卡片隨之更新。

「複製給 AI」把同樣的標註以 Markdown 形式放進剪貼簿（原文作為引用，後面跟你的意見），可以用在任何聊天或工具裡。

### 每則標註的位置

每則標註記下原文、行號和足夠多的上下文，用來重新找到它。檔案改動後，外掛在新文字裡找這段原文；如果上下文不夠唯一、沒有把握，就不去猜：這則標為「原文已變」，保留原來的文字。

### 資料存在哪裡

- 標註、它們的狀態以及最近的文件列表：SQLite，位於 `~/.hermes/plugin-data/diple-docs/data.db`，依檔案路徑區分。不會在你的文件旁邊寫任何檔案。
- 版面選擇（清單寬度、顯示或隱藏、檢視）：Hermes 桌面版的桌面外掛儲存空間（鍵名以 `hermes.plugin.diple-docs.` 開頭）。

設計決策記錄在 [docs/adr](docs/adr/README.md)，整體結構見 [docs/architecture.md](docs/architecture.md)。

## 隱私

所有資料都留在你的電腦上。外掛自己不發任何網路請求，也沒有遙測。它只讀你開啟的文件，並拒絕讀取存放憑證或 Hermes 內部資料的位置（例如 `~/.ssh` 或 Hermes 的 `.env`）。只有你把標註傳進對話時，它們才會到達模型服務商，和你自己打的字一樣。

## 已知限制

主要幾條（完整列表和原因見 [docs/known-limitations.md](docs/known-limitations.md)）：

- 傳送需要圈批。沒裝時，第一次傳送會等 3 秒回執（傳到別的對話時等 10 秒，因為圈批要先切過去），然後頁面提示圈批沒有回應，並關閉傳送；清單、意見、「複製給 AI」和「全部複製為 Markdown」照常可用。
- 傳送目標只能是已有的對話：這裡無法新建對話，因為 SDK 的 `newChat()` 不回傳對話 id。_(issue not filed yet)_
- 在排版檢視裡，表格、原始 HTML 或註腳裡的選取範圍可能對不上原始碼；這時頁面會請你切到原始碼檢視重新選取。
- 檔案改名或移動後，清單從空開始。
- 如果另一個外掛也會改寫 AI 的回答，「用圈批·文檔開啟」卡片可能遺失（宿主只保留第一個改寫結果）；檔案仍然在「最近的文件」裡。

## 相容性

在 Hermes Agent **v0.22.5 (2026.9.24)**、提交 `bf0203a`（2026-10-22）、macOS 上測試，搭配圈批 0.2.2。需要 Hermes 桌面版（只有 CLI 時不會載入桌面外掛）。其他版本也許能用，但沒有測試過，歡迎回報。

## 姊妹外掛：圈批

[圈批（Diple）](https://github.com/waiclay-349687/hermes-diple) 是這個家族裡負責聊天的那一個：在對話裡劃出段落、寫上意見，攢在輸入框上方的待發列表裡，隨下一則訊息送出；AI 逐條回應每則意見，你可以在回答和原文之間來回跳轉。

- **沒裝圈批時**：開啟文件、標註、清單、篩選、標為已解決、頁邊狀態列、傳送選單裡的「複製給 AI」和「全部複製為 Markdown」都能用；只有傳送到對話需要圈批。
- **裝了圈批後**：「傳送 N 則 ▾」把文件裡的標註放進對話的待發列表，和聊天裡摘的標註一起，以膠囊的形式出現在輸入框上方；它們隨你的下一則訊息送出；在選單裡直接選對話，則會馬上送出。AI 的回答會標明在回應哪一則意見，這裡的卡片隨之變成「已發」，然後是「已回應」。

兩者是獨立的外掛，各有儲存庫和發佈版本，可以只裝一個，也可以都裝。執行時不共用任何程式碼：各自打包了一份共用核心。

## 與同類功能的區別

Hermes 桌面版內建的預覽可以顯示 Markdown 檔案，也可以編輯。圈批·文檔從不編輯：它是用來審閱的。它依檔案保存標註清單、跨對話保留，檔案改動後重新找回位置，追蹤每一則從待發到已回應再到已解決，並透過圈批交給聊天。
